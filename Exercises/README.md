# 💪 Exercises

Practice problems to solidify your understanding. Start where you're comfortable and work your way up!

---

## 📚 How to Use These Exercises

1. **Start at your level** — Don't jump to advanced if you're struggling with basics
2. **Try without solutions** — Spend 15-30 minutes before checking
3. **Understand the solution** — Don't just copy, understand WHY it works
4. **Modify and experiment** — Change inputs, add features, break things on purpose

---

## 📊 Difficulty Levels

| Level | Prerequisites | Focus |
|-------|---------------|-------|
| **Beginner** | Modules 00-01 | Variables, loops, functions, basic data structures |
| **Intermediate** | Modules 00-07 | OOP, algorithms, design patterns |
| **Advanced** | All modules | Complex problems, optimization, real-world scenarios |

---

## 🎯 Levels Overview

### Beginner Exercises

Focus on foundational concepts:

- **Variables & Types** — Type conversions, operators
- **Control Flow** — if / elif / else, conditional expressions
- **Loops** — For/while, nested loops, comprehensions
- **Functions** — Parameters, return values, scope
- **Data Structures** — Lists, strings, dictionaries, sets

→ [Beginner Exercises](beginner/README.md)

### Intermediate Exercises

Combine multiple concepts:

- **Object-Oriented Programming** — Classes, inheritance, polymorphism
- **Functional Programming** — Lambdas, map/filter/reduce, decorators
- **Algorithms** — Searching, sorting, recursion
- **Data Structures** — Stacks, queues, trees, graphs
- **Error Handling** — Exceptions, custom errors

→ [Intermediate Exercises](intermediate/README.md)

### Advanced Exercises

Complex, multi-step problems:

- **System Design** — Architecture, patterns, SOLID
- **Performance** — Big O, optimization techniques
- **Concurrency** — Threads, async programming, race conditions
- **Real-world Applications** — File I/O, APIs, databases
- **Testing & Debugging** — TDD, mocking, debugging strategies

→ [Advanced Exercises](advanced/README.md)

---

## 💡 Tips for Success

1. **Time yourself** — Track how long each exercise takes
2. **Write pseudocode first** — Plan before you code
3. **Test edge cases** — Empty inputs, large numbers, duplicates
4. **Comment your code** — Explain your thought process
5. **Review regularly** — Come back to earlier exercises after learning more

---

## 🚀 Getting Started

Pick your level and dive in:

```bash
# If you're new to programming
cd beginner

# If you know OOP and algorithms
cd intermediate

# If you're comfortable with all concepts
cd advanced
```

**Happy coding!** 💻
