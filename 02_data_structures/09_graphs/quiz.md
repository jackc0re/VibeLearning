## Question 1
What is a vertex?

A) A connection  
B) A node  
C) A path  
D) A weight

<details>
<summary>Click for answer</summary>

**B) A node**

Vertices (nodes) are connected by edges.

## Question 2
BFS uses what data structure?

A) Stack  
B) Queue  
C) Array  
D) Tree

<details>
<summary>Click for answer</summary>

**B) Queue**

BFS explores level by level using FIFO.

</details>

## Question 3
DFS uses what data structure?

A) Stack  
B) Queue  
C) Heap  
D) Hash

<details>
<summary>Click for answer</summary>

**A) Stack**

DFS goes deep first, uses LIFO (or recursion).

</details>

## Question 4
Adjacency list space complexity?

A) O(1)  
B) O(V)  
C) O(V + E)  
D) O(V²)

<details>
<summary>Click for answer</summary>

**C) O(V + E)**

Stores all vertices and edges.

</details>

Directed graph edge example?
