## ⚡ Quick Start

There is nothing to install to *read* this repo, and nothing to install to *run* it
either — every example uses the Python standard library only.

```bash
# 1. Check your Python version (3.8 or newer)
python --version

# 2. Pick a topic and run its examples
cd 01_foundations/01_variables_and_types
python examples.py
```

> **Windows note:** use `python` (not `python3`) and make sure Python is added to your
> `PATH` during installation. All examples are plain scripts — no build step, no
> virtual environment required.

Each topic gives you four files:

| File | Purpose |
|------|---------|
| `README.md` | Theory, explanations, real-world analogies |
| `examples.py` | Runnable demonstrations you can run and edit |
| `exercises.py` | Practice problems (solutions at the bottom) |
| `quiz.md` | Quick knowledge check to confirm it stuck |

## 🗺️ Recommended Learning Path

1. **Start with [Getting Started](00_getting_started/README.md)** — get Python running and learn how this repo is organized.
2. **Follow the numbered modules in order** — they build on each other, basic to advanced.
3. **For each concept:** read the `README.md`, run `examples.py`, then try `exercises.py`,
   and finish with `quiz.md`.
4. **After a few modules, build a [project](Projects/README.md)** — that is where it clicks.

For a version of this path with time estimates, see [ROADMAP.md](ROADMAP.md).

## 💡 Tips for Success

1. **Don't just read — code along!** Type out the examples yourself.
2. **Experiment** — modify the examples and see what happens.
3. **Practice consistently** — 30 minutes daily beats 5 hours once a week.
4. **Use the exercises** — they are designed to reinforce learning.
5. **Ask questions** — if something doesn't make sense, dig deeper.
