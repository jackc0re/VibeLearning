# 📝 Cheatsheets

Quick syntax references for the things you look up most often. Skim one while you
write code, print one for your desk, or use them as a refresher before a quiz.

| Cheatsheet | Covers | Reach for it when... |
|------------|--------|----------------------|
| [Python Basics](python_basics.md) | Operators, control flow, functions, exceptions | You forget a piece of syntax |
| [Data Structures](data_structures.md) | List/dict/set/tuple methods and operations | You're working with collections |
| [OOP](oop_cheatsheet.md) | Classes, inheritance, magic methods, SOLID | You're designing classes |
| [Functional Programming](functional.md) | Lambdas, `map`/`filter`/`reduce`, closures | You're writing functional-style code |
| [File I/O](file_io.md) | File modes, JSON/CSV, `pathlib` | You're reading or writing files |
| [Algorithms](algorithms.md) | Big-O notation, sorting, searching | You're analyzing performance |

---

## Suggested use

1. **Before a topic** — skim the matching cheatsheet so nothing looks unfamiliar.
2. **While coding** — keep the relevant one open in a second window.
3. **Before a quiz** — use it as a quick self-check.

Cheatsheets are summaries, not lessons. If something doesn't make sense, the full
explanation is in the module that covers it — see the [main README](../README.md)
for the module list.
